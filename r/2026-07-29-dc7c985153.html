1

MCP ships biggest-ever revision: the stateless 2026-07-28 spec

The Model Context Protocol finalized its 2026-07-28 spec — its largest revision since launch. It removes session state (no initialize handshake or Mcp-Session-Id), makes Extensions first-class (MCP Apps for server-rendered UIs, redesigned stateless Tasks), hardens auth toward OAuth 2.0/OIDC, and adds a 12-month deprecation policy.
⚡ For you: MCP is now load-balancer-friendly and enterprise-auth-aligned, which lowers the cost of running your own agent/tool infra in production. For DPDP-sensitive health workflows, the auth hardening and Enterprise-Managed Authorization path are the exact primitives that make 'build our own agents on vendor models' more viable — a real input to HIH's build-vs-buy calculus.

2

OpenAI open-sources Codex Security — an appsec agent (CLI + SDK)

OpenAI released Codex Security as open source: a CLI and TypeScript SDK that scan repos, validate findings in sandboxes, track them over time, run in CI, and propose fixes as PRs. Announced by Greg Brockman; hit #1 on Hacker News.
⚡ For you: An open, scriptable security-review agent you can drop into CI is directly usable for hardening pharmacy/diagnostics code and the AI-generated code your 10x bets will increasingly produce. It normalizes 'an agent reviews the diff' as table stakes — fold it into HIH's eng-review loop rather than buying a closed scanner.

3

Anthropic: Claude autonomously found cryptographic weaknesses

Anthropic detailed using Claude to find mathematical flaws in cryptographic schemes (the HAWK signature scheme and a weakened AES variant). The run took ~60 hours and ~$100K in API costs; researchers noted models 'think it's impossible so they don't try' — persistence prompting mattered.
⚡ For you: A hard-science signal that frontier models now do genuine novel research given enough compute and the right nudging. For build-vs-buy, it argues the frontier is still pulling away on deep reasoning — favouring renting top models for the hardest HIH problems over self-hosting. Also a caution: the same capability finds weaknesses in your own stack.

Normal day
Product Hunt's top launches converged on one theme — evaluating and self-improving AI agents in production — while Cagan's freshest essay names the AI productivity paradox.
Top 3
1

Prefactor — real-time evals that catch failing AI agents in production

Prefactor launched as Product Hunt's #1 (558+ upvotes), an agent observability + evaluation layer that scores every agent run live in production for quality, drift and risk. Its pitch: 'most agents pass their evals and fail in production.' Drops in via TS/Python SDKs, native to LangChain, Claude, Vercel AI, LiveKit.
⚡ For you: Extends the 'evals are the new PRD' thesis from offline test sets to live production scoring — the missing half for any HIH agent (Rx query bot, symptom triage) where a regression is a safety/compliance event, not a dashboard blip. This is the concrete shape of 'how do we know our agent is still good today.'

2

Cekura — the self-improvement loop for voice agents

Cekura launched at Product Hunt #2 (374+ upvotes), selling a closed loop that simulates calls, evaluates them, and feeds failures back to improve voice agents automatically rather than via manual QA.
⚡ For you: Maps directly to Labs Cx voice/Kapture — the bot-handling %, IPO and aided-order metrics you already track. The clever bit is treating voice QA as a self-tightening loop instead of human spot-checks; that's the 10x version of the manual call-audit process 1mg runs today.

3

Cagan: 'The AI Productivity Paradox'

Marty Cagan's latest SVPG essay argues teams ship faster with AI but outcomes aren't improving — citing data that 89% of execs say AI sped up work while only 6% can point to AI ROI.
⚡ For you: A direct challenge to output-over-outcome drift as AI makes shipping cheap — exactly the trap to guard against when HIH's 10x bets start producing code and features faster. Use it as ammunition to keep the team anchored on behaviour change, not velocity theatre.
