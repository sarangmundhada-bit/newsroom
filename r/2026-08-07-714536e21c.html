AI
Big day
Two structural shifts in one day: agent tooling got a vendor-neutral packaging standard backed by OpenAI, Google, Microsoft and AWS, and Anthropic materially widened what a frontier model will answer about biology and health. Underneath, the open-weights free lunch started to end.
Top 3
1

Anthropic unblocks Fable 5 biology — ~85% fewer health fallbacks

Anthropic retuned Fable 5's biology classifiers, cutting biology-related model fallbacks roughly 85% across surfaces (67% on Claude.ai, 7% on the API/Platform). Lab-result interpretation, symptom explanation and clinical-professional tasks now go through; virology, toxicology, molecular design and drug development still fall back to Opus 5.
⚡ For you: Re-run your HIH lab-report-explainer and symptom-triage eval suites against Fable 5 this week — the eval that failed on 'explain my LFT panel' three months ago is now stale. Note the asymmetry: the Platform-side improvement is 7%, not 67%, so API refusal rate stays your gating risk, not a solved problem.

2

Agent Plugins 1.0: OpenAI, Google, MSFT, AWS agree one plugin format

OpenAI published Agent Plugins, a vendor-neutral 1.0.0 spec packaging Agent Skills plus an mcp.json MCP-server manifest into one portable bundle. Steering committee is Amazon, Cursor, Microsoft, OpenAI and Vercel, with Google as core maintainer; ChatGPT, Codex, Cursor, GitHub Copilot, Kiro and VS Code support it at launch.
⚡ For you: Stop writing per-client wrappers for 1mg's internal agents — repackage the Databricks-SQL, Rx-validation and clickstream-instrumentation skills as one Agent Plugin so pharmacy and diagnostics PMs load them in whatever client they already use. Use this to kill the lock-in objection in your next build-vs-buy memo: the tooling layer is now portable even when the model isn't.

Amazon Pharmacy ships $50 GLP-1s to Medicare via CMS Bridge Program

Amazon Pharmacy began delivering Wegovy (injectable and oral), Zepbound KwikPen and Foundayo to eligible Medicare Part D members for $50/month under the CMS GLP-1 Bridge Program running through Dec 2027. Amazon automates eligibility verification, prior authorisation and billing, with same-day delivery in 3,100+ US cities and no Prime requirement.
⚡ For you: The unlock was not the drug or the discount — it was automating eligibility, prior auth and billing so the low price could actually be claimed without user effort. Audit where HIH's chronic-care and insurance-linked flows still make the patient do the paperwork; that is the agentic-AI bet with a P&L attached rather than a demo.

1

Cloudflare ships AEO + WebMCP: SEO becomes 'get recommended by the model'

Cloudflare launched an Answer Engine Optimization tool that probes Claude and GPT with real customer prompts and scores your Citation Rate, Prominence, Mention Rate and Share of Voice against competitors — plus WebMCP, a Chrome 146 standard Cloudflare injects at the edge so any site exposes callable tool packs to agents via a dashboard toggle, no code changes. Their framing stat: fewer than half of all HTML page requests now come from a human.
⚡ For you: 1mg's organic moat on 'best medicine for X' and 'lab test for Y' is being re-mediated by assistants that never load your page. Run an AEO-style audit this month — ask Claude and ChatGPT 50 real HIH queries ('thyroid test near me', 'is my HbA1c high') and measure how often 1mg is cited versus PharmEasy, Apollo and Redcliffe — then treat a WebMCP tool pack for lab-test booking and medicine reorder as a Q3 10x bet, not a backlog item.

2

Oji Udezue open-sources 17 Claude Skills that encode PM judgment

3x CPO Oji Udezue published a 17-skill open-source library covering the full lifecycle — problem-finding, what-to-build, activation, monetization, direction, running the work. The design principle is gates: 'LLMs very rarely tell you no. And this skill will tell you absolutely no.' His vet-a-feature skill runs a Sharp Problem Test (current workaround, frequency vs market size, willingness to pay inferred from workaround spend) against a 3x-better bar.
⚡ For you: You already run a skills-based Claude setup — the gap is that your skills produce artifacts and his refuse them. Port the vet-a-feature gate into /mentor and /prd so a bet dies at the Sharp Problem Test before it reaches a PRD, and run the current HIH backlog through the 3x bar this week; anything clearing only 1.2x should be named as such in front of the pod.

3

OpenAI makes frontier chat free and unlimited; retunes Sol to push back

OpenAI made GPT-5.6 Luna the default for Free and Go users with unlimited text chats (limits remain on files, images, tools) plus a Think button for harder questions. The retuned Sol for Plus/Pro is more direct, tighter in formatting, and explicitly built to correct the user when simple agreement wouldn't help — OpenAI claims a large drop in factually wrong responses on medical, financial and legal prompts.
⚡ For you: Every Indian user with a free ChatGPT account now has unlimited frontier-tier health Q&A, which resets the floor HIH's insight layer must clear — generic symptom explanation is a commodity, so your differentiation has to be the user's own lab values, refill history and doctor context. Copy the Sol tuning decision too: ship a disagreement mode so HIH contradicts a wrong self-diagnosis rather than validating it.
