Cursor (post its $60B SpaceX acquisition) shipped Origin on Aug 17: agent-first Git hosting with repos, PRs, reviews, CI inside Cursor, one-click GitHub import, automatic merge-conflict resolution, and environments that start cloud agents 3x faster.
